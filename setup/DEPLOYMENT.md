# こむぎえんGAS デプロイ手順

## 認証情報

管理パスワードはソースコードやHTMLへ書かない。
Apps Scriptの「プロジェクトの設定」→「スクリプト プロパティ」に、次の1件を登録する。

- プロパティ: `ADMIN_PASSWORD`
- 値: パスワード管理ツールで生成した16文字以上の値

Gemini下書き機能を有効にする場合は、Google AI Studioで作成したキーを次のプロパティへ保存する。

- プロパティ: `GEMINI_API_KEY`
- 値: Gemini APIキー

APIキーをHTML、GitHub、スプレッドシートへ記載しない。先生のメモ文字列だけをAPIへ送り、写真は送信しない。

写真フォルダのIDは既存の `SLOT_FOLDER_ID` を維持する。

## デプロイ順序

1. `ADMIN_PASSWORD` と `GEMINI_API_KEY` が設定済みであることを確認する。
2. `gas-code.gs` と実GASプロジェクトのコードが一致していることを確認する。
3. 新しいバージョンを既存WebアプリのデプロイIDへ反映する。
4. 管理画面でログイン、お知らせ追加・非表示、写真変更、保育日保存を確認する。
5. 公開ページで、お知らせ・写真・保育日が反映されることを確認する。

パスワード変更はスクリプトプロパティで行う。変更後は既存セッションが最長6時間残るため、緊急時はコードのトークン用キー名も変更して再デプロイする。
